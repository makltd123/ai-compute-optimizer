# AI Compute Optimizer

[English](README.md) | **Русский**

Исследовательский MVP для проверки гипотезы: внешний слой принятия решений может распределять разнородную ИИ-нагрузку между моделями с разным соотношением цены и качества и снижать теоретическую стоимость инференса, сохраняя заданный уровень качества.

## Что есть в первой версии

- Адаптер Mistral API за абстракцией провайдера.
- Внешний реестр моделей и конфигурация цен.
- Логирование токенов, стоимости и задержки по каждому запросу.
- Загрузчик бенчмарка в формате HumanEval (зависимость `datasets` необязательна).
- Проверка ответов через юнит-тесты на Python.
- Фиксированные базовые стратегии: Cheap / Medium / Strong.
- Офлайн-оракул.
- Первый эвристический роутер: простая задача → cheap, средняя → medium, сложная → strong.
- Утилиты для ограничений по целевому качеству и бюджету.
- Воспроизводимые метаданные экспериментов и результаты в JSONL с возможностью продолжить прерванный прогон.
- Построение графиков и отчётов.

## Научная честность

Реализация не объявляет гипотезу доказанной. Она выдаёт сырые результаты, метрики и графики. Итоговая научная и коммерческая интерпретация остаётся за исследователем.

## Уровни моделей

| Уровень | Модель | USD за 1 млн токенов (вход / выход) |
|---|---|---|
| cheap | Mistral Small 4 | 0.15 / 0.60 |
| medium | Mistral Large 3 | 0.50 / 1.50 |
| strong | Mistral Medium 3.5 | 1.50 / 7.50 |

Уровни названы по цене за токен, а не по названиям моделей: `strong` — это Mistral Medium 3.5, потому что она самая дорогая из трёх.

## Результаты

HumanEval, pass@1 по юнит-тестам бенчмарка, `temperature=0`, `max_tokens=512`. Стоимость теоретическая: посчитана по числу токенов и ценам выше. Сводки лежат в `results/*_summary.json`; сырые логи запросов в репозиторий не входят.

### Фиксированные стратегии: первые 60 задач

| Стратегия | pass@1 | Стоимость, USD | Средняя задержка |
|---|---|---|---|
| cheap | 95.0% | 0.0169 | 3.1 с |
| medium | 58.3%* | 0.0257 | 7.7 с |
| strong | 95.0% | 0.2268 | 5.5 с |

\* 24 из 25 неудачных запросов к medium — это ошибки HTTP 429 (превышен лимит запросов), которые засчитались как проваленные задачи. Модель вернула ответ на 36 задач, и 35 из них решены верно, так что эта цифра отражает ограничение частоты запросов, а не качество модели. Прогон нужно повторить.

### Роутеры: все 164 задачи, целевое качество 90%

| Стратегия | Распределение (cheap / medium / strong) | pass@1 | Стоимость, USD |
|---|---|---|---|
| Эвристический роутер | 141 / 22 / 1 | 89.0% | 0.0665 |
| Оптимизатор стоимости, v1 | 164 / 0 / 0 | 88.4% | 0.0506 |
| Оптимизатор стоимости, финальный | 156 / 8 / 0 | 87.2% | 0.0547 |

- Ни один роутер не достиг цели в 90%.
- Ни один не обошёл простую стратегию «всё на cheap».
- Разброс между прогонами сопоставим с разницей между стратегиями: в двух прогонах оптимизатора 6 из 156 задач, которые оба раза ушли на cheap, изменили результат даже при `temperature=0`.
- Mistral Small 4 и так решает большую часть HumanEval, поэтому этот бенчмарк оставляет мало места для маршрутизации. Для проверки гипотезы, скорее всего, нужна более сложная или более разнородная нагрузка.

## Интеграция с Mistral

Адаптер использует официальный Python SDK `mistralai` и `client.chat.complete(...)`. Доступные модели можно проверить через эндпоинт `/v1/models` своего аккаунта. `MISTRAL_API_KEY` храните только в переменной окружения.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[test,bench]'
cp .env.example .env
export MISTRAL_API_KEY='...'
```

На Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[test,bench]"
$env:MISTRAL_API_KEY = "..."
```

Проверить настроенные модели:

```bash
python -m src.utils.registry
```

Запустить локальные тесты:

```bash
pytest -q
```

Запустить эксперимент 001 (нужны API-ключ и зависимость для бенчмарка):

```bash
python -m experiments.exp001_smoke_test.run
```

Запустить эксперимент 004, оптимизатор стоимости (нужен API-ключ):

```bash
python -m experiments.exp004_router.run
```

## Перед тем как публиковать цифры

В `configs/pricing.yaml` — стандартные (не пакетные) цены Mistral API, сверенные 12.08.2026. Цены меняются, а псевдонимы `*-latest` со временем могут указывать на более новые модели, поэтому перед тем как приводить стоимость, перепроверьте и то и другое и запишите ID моделей, которые фактически вернул API.
